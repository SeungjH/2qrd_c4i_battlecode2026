# Explorer v13 — C++ 휴리스틱 봇

각 드래곤이 같은 프로그램을 독립 실행하며 시야·몸통 좌표 기억·소나로 협력합니다. RL은 사용하지 않습니다.

## 제출

`./package_submission.sh` → **`dist/2qrd_v13.zip`**. 커밋된 `main.cpp`, `bot.toml`만 포함하고 4 MB 미만입니다. ZIP은 GitHub에 올리지 않습니다.

## v12에서 변경한 내용

### 몸통 좌표 기억

머리부터 꼬리까지 좌표를 이동·성장·분열에 맞춰 갱신하고 관측과 대조합니다. 포털 출구가 시야 밖이어도 기존 몸통 기억을 지우지 않고 다음 관측에서 머리 위치와 길이를 맞춥니다. 별도의 과거 길이·행동 목록은 저장하지 않습니다. 처음부터 관측하지 못한 몸통은 미확인 상태로 둡니다.

### 막다른 길에서 기존 머리 2칸만 희생

길이 N ≥ 4인 드래곤은 머리의 물리적인 출구가 막혔고 꼬리 쪽 탈출 공간이 확인되면 `SPLIT N-2`를 선택합니다. 기존 머리 쪽 2칸을 남기고, 나머지 N−2칸은 옛 꼬리를 새 머리로 삼아 반대쪽으로 탈출합니다. 4→2+2, 6→2+4뿐 아니라 분열 가능한 모든 길이에 같은 계산을 적용합니다.

- 기존 머리 2칸은 희생 상태로 고정합니다. 다음 차례에 이동·분열 없이 턴을 종료하면 엔진의 `NoValidAction` 처리로 그 2칸만 제자리에서 사망합니다.
- 분열 자식에게 역방향 탈출 신호를 보냅니다. 몸통·지형 기억으로 시야 밖 꼬리와 꼬리 너머 출구도 평가합니다.
- 이동 점수가 낮다는 이유만으로 희생하지 않습니다. 이동하면서 꼬리가 비워지는 경우도 물리적인 출구로 인정합니다.
- 길이 2·3 또는 팀 개체 수 상한에 도달한 경우 분열할 수 없습니다.

진주 탐색, 일반 분열, 지원·증여, 퀸의 기본 정책은 v12를 유지합니다. 다만 **퀸이 이 탈출 분열을 하면 기존 퀸 ID도 머리 2칸과 함께 사망합니다.** 긴 자식이 퀸 ID를 승계하지는 않습니다.

## v12와 대전 비교

공식 엔진 `unswbc 1.2.3`, 네이티브 `-O2` 실행. 기본 제공 맵 5개 × 시드 101/202/303 × 진영 교대, 총 30경기입니다. 상대는 v12 커밋 `65243ba`입니다.

| 맵 | v13 전략 승 | v12 승 |
|---|---:|---:|
| Autarky | 4 | 2 |
| Default | 4 | 2 |
| Portals | 6 | 0 |
| Schooltime | 5 | 1 |
| Queen of Spades | 2 | 4 |
| 합계 | **21** | **9** |

실행 오류는 0건입니다. 이 결과는 탈출 로직 수정 후, 사용하지 않는 길이·행동 기록 제거와 버전 표기 변경 전 소스로 측정했습니다. 기록 제거 후에는 아래 회귀 검증을 다시 통과했으며 30경기를 재실행하지는 않았습니다. [경기별 원시 결과](docs/v13_comparison.json).

한정된 맵·시드의 결과로 일반 대회 승률을 보장하지 않습니다. Autarky는 제공 리플레이가 아닌 기본 제공 맵입니다. v13의 샌드박스 명령어 예산은 별도로 검증하지 않았습니다.

## 검증

- `tests/run.sh`: 전략 및 프로세스 행동 회귀 검사.
- `tests/engine_reverse_discard.py`: 실제 봇이 통로를 이동하며 몸통을 기억한 뒤, 길이 4·6에서 기존 머리 2칸만 사망하고 나머지 자식이 재분열 없이 생존하는지 공식 엔진으로 검사.
- 시야 밖 몸통 보존, 포털 이동 후 성장 유무, 이동 가능한 꼬리 칸, 분열 상한을 검사.

```sh
./tests/run.sh
clang++ -std=c++20 -O2 -Wall -Wextra main.cpp -o /tmp/explorer-v13
# unswbc 1.2.3이 설치된 Python 사용
python3 tests/engine_reverse_discard.py /tmp/explorer-v13
```

시야 밖 적의 현재 점유나 새 자식에게 전달되지 않은 초기 몸통은 알 수 없으며, 소나도 모든 개체에게 도달하지 않습니다. 따라서 탈출 생존을 보장하지는 않습니다.
