# Explorer v2 — C++ 휴리스틱 봇

업로드 파일: `heuristic_dragon_v2.zip`. ZIP 최상위에는 `main.cpp`, `bot.toml` 두 파일만 들어 있습니다. 웹사이트에서 언어 C++를 선택합니다.

## 이번 변경

1. **방향을 유지하는 탐색**: 출생 시 진행 방향을 기본 방향으로 삼고, 개체 ID에 따라 막혔을 때 좌회전·우회전 우선순위를 정합니다. 매 턴 무작위로 방향을 바꾸지 않습니다. 자식은 분열 후 부모에서 멀어지는 방향으로 출발합니다.
2. **방문 기록**: 개체마다 전역 좌표별 방문 횟수와 최근 방문 라운드를 기억합니다. 처음 되돌아오는 순간부터 이미 지나간 줄보다 새로운 줄을 선호합니다. 벽으로 둘러싸인 공간을 모두 탐색한 뒤에는 적게 방문한 칸을 순회합니다.
3. **아군과 분산**: 주변 아군과의 거리가 증가하는 이동에 보상을 주며, 머리 충돌 가능성과 몸통이 막는 길을 평가합니다. 아군 머리가 가까이 있으면 정기 분열을 미룹니다.
4. **부스터 완전 금지**: 모든 이동 명령은 `MOVE N`, `MOVE E`, `MOVE S`, `MOVE W` 중 하나입니다. 여러 글자 이동 경로를 생성하는 코드 자체가 없습니다.
5. **분열 크기 2 고정**: 모든 분열은 `SPLIT 2`입니다. 길이 L인 부모는 L−2칸을 유지합니다. 정기 분열은 300라운드 전, 길이 5 이상일 때 부모가 다음 이동을 할 공간과 팀 개체 수를 확인하여 수행합니다. 분열 사이 최소 3라운드를 둡니다.
6. **부모 구출**: 자기 몸에 갇힌 부모가 뒤에서 두 번째 칸을 통해 탈출할 수 있으면 2칸만 분열합니다. 새끼는 해당 칸을 비우는 이동을 우선합니다. 진주를 먹으면 그 꼬리 칸이 남아서 부모를 막는 경우, 다른 이동을 찾고 없으면 새끼 2칸만 자기 몸에 부딪혀 희생합니다.
7. **막혔을 때 아군 보호**: 피할 수 없는 사망에서 아군 머리로 돌진하던 마지막 선택을 수정했습니다. 자기 몸·벽·몸통을 우선하여 아군의 동반 사망을 피합니다.
8. **후반 성장**: 300라운드부터 정기 분열을 멈춥니다. 기존 후반 집결과 의도적 자살 합류는 제거하고, 분산 수집으로 생존 개체의 길이를 키웁니다. 비상 분열은 후반에도 2칸으로만 가능합니다.

부모의 머리는 분열 턴에 움직이지 않고, 자식은 같은 라운드 뒤쪽에서 행동합니다. 따라서 **SPLIT 2가 모든 막다른 길을 해결하지는 않습니다.** 부모 탈출구를 만들 수 있는 꼬리 배치를 별도로 처리하며, 이미 완전히 봉쇄되어 구출 경로가 없는 경우에는 최후 수단으로 2칸 분열을 시도합니다.

진주를 향한 거리는 보이는 벽과 몸을 반영한 경로로 계산합니다. 포털은 두 경계를 관측하고 출구가 현재 시야에 있어 안전을 확인할 수 있을 때 이용하며, 개체당 최대 2회 정책을 유지합니다. 안전한 이동도 분열도 불가능할 때만 미확인 포털을 최후 수단으로 사용할 수 있습니다.

각 개체는 독립된 프로그램 인스턴스입니다. 방문 기록과 몸 위치 추적은 개체 내부 메모리에만 있으며, 새끼는 새 기록으로 시작합니다. 리플레이의 `INDICATOR v2 ...` 표시로 분열·꼬리 비우기·새끼 희생 등 선택 이유를 볼 수 있습니다.

## 검증 결과

도구: 공식 `unswbc 1.2.2`, C++20. 대전 상대는 이번 변경 전에 전달한 봇 코드입니다. 공식 맵 각각에서 시드 101로 A·B 진영을 바꿔 2경기씩 실행했습니다.

| 공식 맵 | v2 결과 |
| --- | --- |
| default | 2승 |
| trophy | 2승 |
| portals | 2승 |
| schooltime | 2승 |
| big_empty | 2승 |
| 합계 | 10승 / 10경기 |

대전에서 v2의 이동 168,196개는 모두 1칸이었으며, 분열 1,353개는 모두 `SPLIT 2`였습니다. 프로그램 실행 오류는 없었습니다. 이 결과는 이전 버전 대비 비교이며, 사용자가 만났던 랭크 상대에 대한 승률은 아직 측정하지 않았습니다.

추가 행동 검사:

- 20×20 빈 토러스 맵: 200번 이동에서 201개 위치 방문, 재방문 0회, 방향 전환 11회.
- 벽으로 둘러싸인 9×9 공간: 200번 이동에서 81칸 전체 방문, 충돌 없음.
- 길이 7 정기 분열: 자식 2칸, 부모 5칸 유지.
- 자기 몸에 막힌 부모: 2칸 분열 후 자식이 꼬리를 비우고 부모가 5칸을 유지하며 탈출.
- 꼬리를 비울 수 없는 새끼: 새끼 2칸만 희생.
- 출구 없는 개체: 아군 머리를 공격하지 않고 자기 몸 선택.
- 앞에 아군이 있는 개체: 옆 방향으로 거리를 벌림.

최종 코드의 공식 샌드박스 경기(default, 시드 101)도 통과했습니다. 500라운드 동안 v2 12,561턴을 실행했으며, 턴당 CPU points 최대 약 5.0M, 중앙값 약 4.4M이었습니다. 공식 한도는 100M입니다.

