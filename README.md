# Explorer v14 — C++ 휴리스틱 봇
This repo was created to host our team's bot for the UNSW Battlecode2026 competition. The READMEs are written in Korean. 

**RL 실험 기록:** [공격 전용 C++ 봇·내장 모델·대전 결과](research/attack_rl/README.md). 원본 v14 대비 60경기 31승 29패로, 우위가 입증되지 않아 공식 버전은 v14로 유지했습니다.

각 드래곤이 같은 프로그램을 독립 실행하며 시야·몸통 좌표 기억·소나로 협력합니다. RL은 사용하지 않습니다.

## 코드 구조

전역 전략 상태는 드래곤별 `Bot` 안에 캡슐화했습니다. 관측·월드·탐색·통신·먹이지원·전투 상태를6개 그룹으로 구분하고,91개 기존 함수를 역할별 헤더로 분리했습니다. 턴 처리도 입력 → 종료 행동 → 기억 갱신 → 판단 → 실행 → 출력 순서로 드러납니다. [파일별 책임과 수정 규칙](src/Agent.md).

리팩터링 전후100경기217,840턴의 MOVE/SPLIT/SONAR/INDICATOR 포함 전체 출력이 바이트 단위로 동일했습니다. 공식 심판3개 전체 경기에서도5,186턴의 출력과 점수가 같았고 계산량·메모리 제한을 만족했습니다. 전략53개·프로세스 행동 회귀 통과. 기존 `engine_trap.py` 경고 송신 실패는 그대로이며, 이번 작업은 가중치와 판단 우선순위를 바꾸지 않습니다. [검증 보고서·재현](analysis/asides-v13-review/refactor/report.ko.md).

현재 배포 버전은 **v14**입니다. 위 출력 동일성 검증은 버전 라벨 변경 전 코드 기준이며, v14에서는 indicator 라벨만 변경하고 전략은 유지했습니다.

## 제출

`./package_submission.sh` → **`dist/2qrd_v14.zip`**. 커밋된 `bot.toml`과 `src/`를 포함하고4MB 미만입니다. 공식 제출 입력은 `src/entry.cpp`와 `src/*.hpp`이며 실제15파일/단일.cpp 빌드를 검증했습니다. 루트 `main.cpp`는 로컬 명령 호환 래퍼로 제출하지 않습니다. 두 진입점을 동시에 컴파일하지 마세요. 미커밋·미추적 소스가 있으면 패키징을 거부합니다. ZIP은 GitHub에 올리지 않습니다.

## v12에서 변경한 내용

### 몸통 좌표 기억

머리부터 꼬리까지 좌표를 이동·성장·분열에 맞춰 갱신하고 관측과 대조합니다. 포털 출구가 시야 밖이어도 기존 몸통 기억을 지우지 않고 다음 관측에서 머리 위치와 길이를 맞춥니다. 별도의 과거 길이·행동 목록은 저장하지 않습니다. 처음부터 관측하지 못한 몸통은 미확인 상태로 둡니다.

### 막다른 길에서 기존 머리 2칸만 희생

길이 N ≥ 4인 드래곤은 머리의 물리적인 출구가 막혔고 꼬리 쪽 탈출 공간이 확인되면 `SPLIT N-2`를 선택합니다. 기존 머리 쪽 2칸을 남기고, 나머지 N−2칸은 옛 꼬리를 새 머리로 삼아 반대쪽으로 탈출합니다. 4→2+2, 6→2+4뿐 아니라 분열 가능한 모든 길이에 같은 계산을 적용합니다.

- 일반 개체의 기존 머리 2칸은 희생 상태로 고정합니다. 퀸은 다음 관측에 안전한 출구가 생겼으면 희생 상태를 취소하고 이동합니다. 출구가 없으면 `NoValidAction`으로 그 2칸만 제자리에서 사망합니다.
- 분열 자식에게 역방향 탈출 신호를 보냅니다. 몸통·지형 기억으로 시야 밖 꼬리와 꼬리 너머 출구도 평가합니다.
- 이동 점수가 낮다는 이유만으로 희생하지 않습니다. 현재 비어 있는 칸을 물리적인 출구로 인정합니다. 자기 꼬리는 충돌 검사 후에 움직이므로 현재 출구로 인정하지 않습니다.
- 길이 2·3 또는 팀 개체 수 상한에 도달한 경우 분열할 수 없습니다.

진주 탐색, 일반 분열, 지원·증여는 유지합니다. 퀸이 자기 꼬리에 막혔다면 머리를 버리는 대신 **꼬리 2칸을 분리해 자식만 희생**하고 원래 퀸 ID를 보존합니다. 새 자식은 관측으로 아군 퀸이 실제로 막혀 있고 자기 머리 칸을 비우면 출구가 생기는지 확인한 경우에만 희생합니다. 그 외의 역방향 탈출 자식은 퀸 ID를 승계하지 않습니다.

## 검증

- `tests/run.sh`: 전략 및 프로세스 행동 회귀 검사.
- `tests/engine_reverse_discard.py`: 실제 봇이 통로를 이동하며 몸통을 기억한 뒤, 길이 4·6에서 기존 머리 2칸만 사망하고 나머지 자식이 재분열 없이 생존하는지 공식 엔진으로 검사.
- 시야 밖 몸통 보존, 포털 이동 후 성장 유무, 이동 가능한 꼬리 칸, 분열 상한을 검사.

```sh
./tests/run.sh
clang++ -std=c++20 -O2 -Wall -Wextra main.cpp -o /tmp/explorer-v14
# unswbc 1.2.3이 설치된 Python 사용
python3 tests/engine_reverse_discard.py /tmp/explorer-v14
```

시야 밖 적의 현재 점유나 새 자식에게 전달되지 않은 초기 몸통은 알 수 없으며, 소나도 모든 개체에게 도달하지 않습니다. 따라서 탈출 생존을 보장하지는 않습니다.

## 꼬리 충돌·퀸 생존 수정의 직접 검증

제공 리플레이 10개를 해독하고 자기 꼬리 판정, 퀸 꼬리 자식 희생, 분열 후 안전한 출구 재확인을 수정했습니다. 원본 v13 대비 최종 소스의 공식 엔진 네이티브 100경기는 **55승 35패 10무**, 오류0건입니다. 새 로그 맵 50경기는 **35승 15패**, 기존 로그 맵 50경기는 20승20패10무입니다. 실제 맵은 9종이며 Autarky 조건10경기가 두 묶음에 중복됩니다.

최초 기능 수정 당시 전략52개·프로세스 행동 회귀 통과, 엔진 회귀9개 중8개 통과입니다. `engine_trap.py`의 DANGER 송신 검사는 원본에서도 같은 조건으로 실패한 기존 문제이며 아직 남겨 두었습니다. 공식 심판용 WASM 빌드 및 3개 맵의 첫25라운드 계산량·메모리 계측도 통과했습니다. 한정된 상대·맵·시드 결과로 일반 대회 성능을 보장하지 않습니다. [진단·원시 결과·실행 방법](analysis/asides-v13-review/report.ko.md).
