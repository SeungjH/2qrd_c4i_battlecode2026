# Explorer v10 — C++ 휴리스틱 봇

각 드래곤이 같은 프로그램을 독립 실행합니다. 자기 시야·이동 기억·소나를 사용하며 **RL과 스프린트는 사용하지 않습니다.**

## 제출

`./package_submission.sh` → **`dist/2qrd_v10.zip`**. ZIP 최상위에는 커밋된 `main.cpp`, `bot.toml`만 들어갑니다. 4 MB 미만을 확인하고, ZIP은 GitHub에 올리지 않습니다.

## v10 변경

### 진주와 순환 탈출

- 보이는 진주로 가는 최대 10칸 경로를 실제 몸 모양으로 재생합니다. 도중에 먹는 진주는 꼬리를 유지하고, 몸 충돌을 확인합니다. 마지막 식사 후 공간·출구 조건을 실제 이동의 `safeMove` 조건과 맞춥니다.
- queen과 후반 긴 개체는 추가 6수 생존 검사를 적용합니다. 짧은 정찰병의 기존 비상 분열 선택지는 유지합니다. 다른 몸통은 짧은 예측 중 고정하며, 시야 밖 점유나 미관측 지형은 보장할 수 없습니다.
- 초기 몸 기억이 불완전하면 이를 위험의 증거로 간주해 진주를 금지하지 않습니다. 기존 즉시 이동 검사를 적용합니다.
- 먹기 위험하다고 확인된 목표는 24라운드 접근을 보류합니다. 바로 옆 진주의 마지막 이동이 안전하지 않은 경우도 기록합니다. 8턴 순환 탈출 중에는 진주·수익 구역·수익형 함정 경로가 탈출을 덮어쓰지 않습니다.
- 경로 예측의 6수 탐색 예산은 턴 전체 256개 상태로 제한합니다. 예산이 소진되면 미래 검사는 낙관적으로 종료하지만, 현재 충돌·마지막 공간 검사는 유지합니다. 경로 배열은 개체별 고정 버퍼로 두어 WASM 스택을 압박하지 않게 했습니다.

### 마지막 150라운드 수집·증여

- R350 이후, 80턴 이상 관측한 개체가 최근 80라운드 동안 적을 보지 못했다면 증여를 강화합니다. **로컬의 조용한 상태이며 맵 전체가 분리됐다는 판정은 아닙니다.** 적을 보면 일반 조건으로 돌아갑니다.
- 이때 길이 2–12 공여자를 허용합니다. 공식 queen이 최우선이며, queen 사망이 확인되었거나 아직 ID를 모르면 기존 최장 개체 보조 전략을 사용합니다.
- R350–399에도 안전하게 회수 가능한 진주가 예상 사체 진주의 절반 이상 보이면 부분 증여를 허용합니다. 평상시에는 해당 기간에 전체 회수 조건을 유지합니다. 희생 직전 최신 길이·실제 머리·회수 경로·공간·두 출구·주변 적을 다시 확인합니다.
- 살아 있는 queen과 수집 개체만 둘 남으면 R470까지 마지막 수집병을 보존합니다. 이후에는 시간 안에 회수 가능한 증여를 진행합니다. queen 자신은 공여하지 않습니다.
- 공여자 순서, 진행로 보호, OFFER/ACCEPT, 실제 생성된 진주 회수, 집결 장소, 실패한 접근 후 수집 복귀를 유지합니다. 회수 예약과 주변 진주 점수로 다른 아군의 가로채기를 억제하지만 독점 회수를 보장하지는 않습니다.
- queen의 일반 분열·사냥·포털·수익형 함정 진입 금지를 유지합니다. 안전한 순환은 강제로 벗어나지 않습니다. 일반 개체의 비상 분열을 일괄 차단한 실험은 약해져 제외했습니다.

## 근거와 검증

M855142의 Sol 분석은 사용자가 전달한 경기 관측으로 채택했습니다. 원본 재검증을 수정의 전제 조건으로 삼지 않았습니다. 긴 순환의 원인으로 제시된 “첫 단계는 안전하지만 마지막 식사가 위험한 목표”를 합성 맵에서 재현해, 목표를 거부하고 냉각 시간을 기록하는지 검사합니다.

공식 unswbc 1.2.3, 여섯 맵·시드 101/202/303/404·양 진영 48경기에서 **v9 대비 25승 23패**였습니다.

| 맵 | v10 승 | v10 queen 생존 | v9 queen 생존 |
|---|---:|---:|---:|
| default | 4/8 | 1 | 2 |
| devil | 5/8 | 0 | 0 |
| dilemma | 2/8 | 0 | 0 |
| portals | 6/8 | 0 | 0 |
| trauma | 4/8 | 7 | 6 |
| trophy | 4/8 | 0 | 0 |

Portals는 6승 2패였습니다. 작은 비교이며 상위팀 상대 예상 승률이나 전체 성능의 뚜렷한 향상으로 해석할 수 없습니다.

Trauma 시드 101의 공식 WASM 샌드박스는 500라운드를 완료했습니다. v10은 queen 8 대 17로 패배했으며, CPU 초과·메모리 오류는 없었습니다. 턴당 CPU 중앙값 **5.4M**, 최대 **6.7M / 제한 100M**이었습니다.

```sh
./tests/run.sh

python3 tests/engine_scoring.py
python3 tests/engine_donation.py /tmp/explorer-v10
python3 tests/engine_donation.py /tmp/explorer-v10 small
python3 tests/engine_reverse.py /tmp/explorer-v10
python3 tests/engine_ambush.py /tmp/explorer-v10
python3 tests/engine_trap.py /tmp/explorer-v10
```
