# Explorer v8 — C++ 휴리스틱 봇

드래곤마다 같은 C++20 프로그램이 독립 실행됩니다. 자기 시야와 기억, 소나만 사용하며 RL과 스프린트는 사용하지 않습니다.

## 제출

`./package_submission.sh`로 **`dist/2qrd_v8.zip`**을 만듭니다. ZIP 최상위에는 커밋된 `main.cpp`, `bot.toml` 두 파일만 들어갑니다. 수정한 소스를 커밋하지 않았거나 ZIP이 4 MB 이상이면 패키징을 중단합니다. ZIP은 GitHub에 올리지 않습니다.

## v8 변경 사항

### 진주 수집과 탐색

- 보이는 진주는 벽·몸통을 고려한 실제 경로가 10칸 이내이고 첫 이동이 안전하면 우선합니다. 소나 임무와 위험 회피가 우선할 수 있습니다.
- 새 칸을 밟는 것과 새 구역을 관측하는 것을 구별합니다. 300라운드 전 길이 2–3 정찰병은 생존 8턴 이후 최근 8라운드 수입이 없으면, 순환에 빠지기 전부터 기억한 통로로 미탐색 경계를 찾아갑니다. 도착해서 새로 보게 될 7×7 영역의 미관측 칸 수를 목표 점수에 반영합니다. 보이는 안전한 진주가 있으면 수집 경로가 우선합니다.
- 진주가 빠르게 다시 나오는 칸을 관측으로 추정합니다. 연속 관측에서 생성 카운트다운이 1인 칸과 반복 수집한 칸을 최대 32개 기억하고 소나로 중계합니다. 원래 관측 시각을 유지하고 오래된 정보는 지웁니다. 실제 생성 주기를 미리 안다고 가정하지 않습니다.
- 공유된 수익 구역은 수입이 끊긴 개체가 찾아가며, 주변 아군이 2마리 이상인 구역은 피합니다. 아군 분산과 기존 순환 탈출도 유지합니다.
- M845229의 v7 주황은 50라운드에도 중앙 진주 상당 부분을 관측하지 못했고 총 수집량이 21 대 348이었습니다. 이 사례가 미탐색 경계 탐색 보완의 근거입니다.

### 후반 여왕 증여

- 소나로 후보 ID·길이·좌표·원래 관측 시각을 중계합니다. 최신 길이를 후보별로 저장해 줄어든 후보의 오래된 길이를 다시 믿지 않도록 했습니다. 후보 정보는 40라운드 후 만료하며, 350라운드부터 길이 3 이상의 작은 후보도 중계합니다.
- 350–399라운드에는 길이 2–6이 길이 8 이상 여왕을 지원하고, 400라운드부터 길이 2–12가 충분히 긴 여왕을 지원합니다. 기존 10칸 접근 제한을 없앴으며 남은 시간과 안전한 경로로 판단합니다.
- 길이 4 이하 공여자는 400라운드부터 더 긴 여왕의 최신 소나·실제 머리가 2칸 이내에 있고, 모든 예상 진주가 회수 가능하며 적이 가까이 없으면 답신을 기다리지 않고 증여합니다. 다른 공여자는 제안·확인 또는 근접 대기 후 증여합니다.
- 공여자는 여왕의 진행 방향 앞쪽으로 접근합니다. 여왕은 한 번에 한 공여자를 받으며, 다른 아군은 회수 예약 진주와 새로 관측된 여왕 주변 진주를 피하도록 점수를 낮춥니다. 이동 가능한 실제 경로와 경쟁 상황 때문에 독점 회수를 보장하지는 않습니다.
- 제안 좌표를 진주로 취급하지 않습니다. 아직 죽지 않은 공여자의 몸을 기다리며, 실제로 보이는 진주만 회수합니다. 회수가 성립하지 않으면 6라운드 안에 임무를 해제합니다.

### 분열·긴 개체 보호

- 정기 분열은 꼬리 2칸을 분리합니다. 초반 길이 5 이상이 기본이고, 길이 4는 수입·주변 진주 또는 큰 맵 정찰 조건을 확인합니다. 300라운드부터 정기 분열을 중단합니다. 비상 탈출 분열은 계속 허용합니다.
- 자기 몸 때문에 막히면 기존 머리를 2칸 남기고 긴 뒷부분을 반대로 보내는 비상 분열을 유지합니다. 꼬리가 시야 밖이면 자신의 이동으로 기억한 몸·지형을 사용하므로 먼 곳의 현재 점유에는 불확실성이 있습니다.
- 후반 긴 개체는 포털 진입을 금지하고 적 머리·작은 공간을 피합니다. 움직이는 꼬리를 반영한 최대 6수 탐색으로 다음 몇 이동에서 막히는 후보를 추가로 걸러냅니다. 제한된 시야와 탐색 깊이 때문에 생존을 보장하지는 않습니다.
- 진주가 충분한 작은 막다른 구역은 짧은 정찰병이 진입하고 긴 꼬리 자식으로 탈출할 수 있습니다. 입구 위험 경고는 아군들이 중계합니다.

### 사냥·꼬리 매복·포털

- 350라운드 전 길이 2–4의 짧은 개체들이 적 머리의 서로 다른 출구를 차단합니다. 소나의 동료 차단 방향을 실제로 반영하며 벽 많은 맵도 제외하지 않습니다. 최대 30라운드, 8라운드 무진전 또는 짧은 순환이면 해제합니다.
- **M844581의 30라운드 꼬리 매복**을 반영했습니다. 적 머리가 자기 꼬리 옆에 접근하면 꼬리 2칸을 분리해 방향을 뒤집습니다. 새 자식은 그 턴에도 적 머리가 옆에 있고 적 몸이 최소 4칸 관측될 때만 동반 충돌합니다. 부모는 긴 부분을 보존하며, 부모가 안전하게 움직일 수 없는 상황에서는 공격용 분열을 하지 않습니다. 나중 ID 적은 직진 1수를 예상하되 실제 자식 행동에서 다시 확인합니다.
- 기존 초반 작은 정찰병의 큰 상대 머리 교환을 유지합니다. 후반에는 여왕 근처 길이 2–3 호위병도 관측상 큰 적과 교환할 수 있습니다.
- 작은 정찰병의 미확인 포털 탐색, 출구 소나 중계, 함정 경고, 동일 포털 12라운드 재진입 제한을 유지합니다.

## 소나 64비트 구성

| 필드 | 비트 수 |
|---|---:|
| 프로토콜 표시 `0xD7` | 8 |
| 팀 | 1 |
| 메시지 종류 | 3 |
| 송신/원본 개체 ID | 16 |
| 원래 관측 라운드 | 9 |
| 종류별 데이터 | 27 |

한 패킷에 모든 정보를 담는 방식이 아닙니다. 네 방향에 여왕 정보·임무·수익 구역/포털·상태를 나눠 보내며 회신 방향을 우선합니다. 수익 구역은 포털 종류의 데이터 비트 26을 구별 표지로 사용합니다. 사냥 데이터는 위치 12비트, 적 ID 12비트, 차단 방향 2비트, 차단 주장 1비트입니다. 4095를 넘는 적 ID는 시야 판단으로 대응합니다. 위험 경고 기억은 최대 64개이며 오래된 임시 경고부터 지웁니다. 소나 경로가 벽·몸통 등에 막히므로 모든 아군에게 즉시 전달되지는 않습니다.
